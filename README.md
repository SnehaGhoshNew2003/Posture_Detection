# PoseNet Demo

## Overview
This project is a web-based **PoseNet Demo** that utilizes **p5.js** and **ml5.js** to estimate human poses in real time. It demonstrates the application of machine learning for pose detection directly in the browser.

## Technologies Used
- **p5.js** – A JavaScript library for creative coding.
- **ml5.js** – A friendly machine learning library built on TensorFlow.js.
- **PoseNet** – A pre-trained deep learning model for pose estimation.

## Setup & Installation
1. Clone or download the repository.
2. Ensure you have an internet connection to load external libraries.
3. Run the `index.html` file in a browser.

## File Structure
- `index.html` – Main webpage for the demo.
- `sketch.js` – JavaScript file that initializes PoseNet and handles pose detection.

## How to Use
1. Open `index.html` in a browser.
2. Allow webcam access when prompted.
3. Pose in front of the camera to see real-time detection.
